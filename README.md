# Simon Says 🎮

A fun and interactive **Simon Says** memory game built with **HTML**, **CSS**, and **JavaScript**.

## 📝 About

Simon Says is a classic memory game where the player must mimic an ever-growing sequence of colors and sounds. Each round adds a new random color to the sequence, and the player must repeat it by clicking the correct buttons. If the player makes a mistake, the game ends.

This project was created for learning purposes, focusing on JavaScript DOM manipulation, event handling, and basic game logic.

## 🎯 Features

- Dynamic color sequence generation
- User interaction via mouse clicks
- Visual and sound feedback
- Game-over detection with a restart option
- Simple, responsive design

## 🛠️ Built With

- **HTML5** – Structure
- **CSS3** – Styling and animations
- **JavaScript (Vanilla)** – Game logic and interactivity
